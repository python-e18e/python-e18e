Runtime choices worth knowing

uvloop is an optional event loop for asyncio. Keep asyncio APIs and, where you control the entry point, use uvloop.run(main()). This is performance information, not a migration: benchmark your workload and check Python and platform support. Windows applications should retain the built-in asyncio loop.

Our catalog treats httpx as deprecated in favor of the Pydantic-maintained HTTPX2. Use httpx2 in dependencies and imports. Review the migration guidance for Python version requirements, TLS behavior, and integration compatibility.
